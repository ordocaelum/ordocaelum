# Launch Plan: Core Pack + First Expansions

Follows the source doc's "build a Core pack, then fragment" strategy.

## Entry product: "Ordo PSX Shader Kit"
- The full shader kit from the style bible §4 + 20 sample props + demo scene.
- Price $10–15. Works on the buyer's *own* assets, so it brings in customers for the core pack.
- Target: shipped by week 6.

## Core pack: "Core: Occult Abbey"
Enough to prototype a complete short horror game.
- **Environment kit (~200):** stone corridors, crypts, chapel, cloister, bell tower, stairs, doors/gates, windows, terrain edges, outdoor graveyard.
- **Props (~150):** altars, pews, candles, censers, grimoires, reliquaries, cages, tools, keys/pickups, gore-light dressing.
- **Characters (10):** cultists (3 robe variants), monk, abbess, pilgrim, possessed villager, 2 creatures, a "celestial" entity, all on the shared skeleton + base animation set.
- **FX/UI:** candle flame, fog cards, dust motes, sigil glow; PSX-style inventory/key icons.
- **Demo scenes:** abbey exterior at night, crypt descent, ritual chamber.
- Price $49–59 list. Target: shipped by week 14.

## Micro-expansion pipeline (each ~30–80 assets, $10–20)
1. Abbey Crypt & Catacombs
2. Cult Ritual Chamber
3. Village of the Order (exteriors)
4. Observatory of the Heavens (cosmic-horror set)
5. Creatures of the Order (characters + animations)

## Ship checklist
- [ ] Every asset meets the style bible §2–3 (tri caps, 64 px/m, ≤256 px textures)
- [ ] Side-by-side check against the golden assets, under the shader kit, in fog
- [ ] Characters retarget cleanly to Unity Humanoid and UE Manny/Quinn
- [ ] Import tested: Unity 6 (URP + Built-in), Unreal 5, Godot 4
- [ ] Overview sheet, 6+ screenshots, 45 s trailer (shot through the shader kit)
- [ ] Store copy, tags ("PSX", "retro", "horror", "low poly", "PS1"), docs PDF, licence
